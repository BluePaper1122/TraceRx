# ResistLens Synthetic Vision Benchmark v1

48 PNG images: 12 fictional source records × 4 imaging conditions. Four orders, four microbiology reports, four review records, rendered in three layouts. No real patient data, external clinical dataset, medical image or drug recommendation was used.

## Conditions

- clean: 1500 × 1600 pixel text page
- blur: Gaussian blur radius 2.4 pixels
- low_resolution: reduced to 450 × 480, then enlarged with bilinear interpolation
- rotated_low_contrast: rotated 3 degrees, contrast factor 0.45

Generation is programmatic with Pillow, preserving exact ground-truth labels. The images are not generated by a language model. Repeat with `python -m resistlens.benchmark --generate`. Exact PNG hashes may depend on Pillow version; the checked-in manifest hashes the delivered files.

## Splits

B01–B06 are development sources (24 images); B07–B12 are test sources (24 images). All variants of a source remain in the same split. Both splits contain all three event types. The test split shares layout families with development: this is not a test of unseen hospital templates. One source has an explicitly undocumented timestamp, whose correct label is null. Unknown and preliminary statuses are present.

## Use

Evaluate extraction of 14 fields, per-condition accuracy, document exact match, failed calls and incorrectly filled null fields. Failures count as incorrect fields. Outputs and quotes require human inspection. Clean-to-degraded comparisons should use all four versions of each selected source. Accuracy includes null fields and may be inflated by them; inspect individual field results as well as the aggregate.

There is no trained or fine-tuned model in this dataset. Existing provider models have unspecified training corpora; do not claim they were trained on MIMIC or these synthetic records. This dataset was authored alongside the app, so it is a held-out source split, not an independently curated external benchmark. A domain reviewer should inspect labels and document plausibility before presenting results.

No claims of clinical accuracy, representative hospital data, real optical scanning artifacts, or clinical utility. The dataset tests extraction, not whether a review actually occurred in a hospital. Test records are not matched longitudinal patient episodes. For temporal workflow regression tests, use the separate authored case fixtures.
